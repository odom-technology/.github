# Support

Public repositories are supported on a best-effort basis. Use the affected
repository's issue tracker for reproducible defects, documentation errors, broken
examples, or narrowly scoped feature requests when issues are enabled. Include the
relevant version and sanitized reproduction details.

For product and service information, use the [contact form](https://odomtech.com/contact/).
Do not submit credentials, private keys, or sensitive personal data. Security concerns
must follow the affected repository's [security policy](SECURITY.md).
Form submissions are reviewed privately and deleted by a daily job after 12 months.

ODOM Tech does not provide emergency operational support through public GitHub issues
and cannot recover credentials or access data that it does not control.
